# BD-0007. Visual direction: transit signage

- Status: Accepted
- Date: 2026-11-23

## Context
Three visual directions were proposed: budget envelopes, a squared notebook, and Buenos Aires subway signage.

## Decision
The visual identity follows subway signage: a strong signage band for the balance, each category shown as a colored "line" with a round badge, movements listed like stations, and one high-visibility color reserved for the main action. The final palette is chosen from several options built on this direction.

## Why
Signage is designed to be read in a second while moving, which matches recording an expense on the phone right after paying. Per-category colors make lists scannable.

## Alternatives considered
- Budget envelopes: implied per-category budgets, which are not decided.
- Squared notebook: the most familiar option and the most common in expense apps; handwriting can look childish.

## Consequences
- Categories need distinct colors; a limited set of category colors repeats when users create many categories, so badges also carry a letter or icon.
- Expenses are never shown in alarm red (see the calm principle in PRODUCT.md).
